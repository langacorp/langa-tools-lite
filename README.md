# LANGA Tools Lite

A WordPress plugin that groups the branding and UI/UX tools LANGA uses across
its own sites: maintenance mode, preloader, favicon override, admin bar
cleanup, ghost pages and credits.

**This repository mirrors the release published on the official WordPress
plugin directory.** The canonical download and the update channel are there:

https://wordpress.org/plugins/langa-tools-lite/

Version in this repository: **1.0.39**

## Install

From WordPress: Plugins → Add New → search for "LANGA Tools Lite".

Manually: download the zip from the directory link above and upload it under
Plugins → Add New → Upload Plugin. Installing from this repository means
copying the folder into `wp-content/plugins/` and renaming it
`langa-tools-lite`.

Requires WordPress 5.7 or later.

## Lite and PRO

Lite is fully functional on its own for branding and UI/UX. A separate PRO
edition adds SEO, forms, GDPR, security hardening, cache, popups, events and
remote management. **PRO is not open source and is not in this repository.**
